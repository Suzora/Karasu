Karasu 让你的 AniList 列表与你的观看和阅读保持同步。它运行在手机上，直接与 AniList 通信，中间没有任何服务器。

在 Android 上，它带来你的列表（含筛选、预设和批量编辑）、当季新番日历、统计和年度回顾、通知、动态流、论坛以及你的个人主页。下拉列表即可同步，长按作品可查看所有可做的操作，从底栏向上滑动可打开命令面板。

四个主屏幕小组件显示今天播出的内容、你正在看和正在读的作品，以及接下来一周的安排——数据取自缓存，自身不联网。后台检查可以在应用关闭时通知你有新剧集。

Android 上的检测依靠 Jellyfin：让 Karasu 指向你的服务器，那里正在播放的剧集就会倒计时并更新进度；如果你允许追踪服务运行，熄屏时也能继续。

通过 F-Droid 安装时，Karasu 的更新由 F-Droid 提供；来自 GitHub 发布页的 APK 则会自己获取更新，并打开系统安装器。Karasu 会与 AniList、你设置的 Jellyfin 服务器通信，每周一次连接 GitHub 获取社区关于剧集如何跨季延续的数据；当你打开某个主页时，还会通过自己的受限请求连接其简介中图片所在的主机。它没有自己的服务器，也没有任何统计分析。
