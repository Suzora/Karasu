Karasu ทำให้รายการ AniList ของคุณตรงกับสิ่งที่คุณดูและอ่าน บนโทรศัพท์ที่คุยกับ AniList โดยตรง — ไม่มีเซิร์ฟเวอร์คั่นกลาง

บน Android มีรายการของคุณพร้อมตัวกรอง ค่าที่ตั้งไว้ และการแก้ไขเป็นชุด ปฏิทินประจำซีซัน สถิติ และสรุปประจำปี การแจ้งเตือน ฟีดสังคม เว็บบอร์ด และโปรไฟล์ของคุณ ดึงรายการลงเพื่อซิงค์ กดค้างที่เรื่องเพื่อดูทุกสิ่งที่ทำได้ และปัดขึ้นจากแถบด้านล่างเพื่อเปิดจัดการคำสั่ง

วิดเจ็ตบนหน้าจอหลักสี่แบบแสดงสิ่งที่ออนแอร์วันนี้ สิ่งที่คุณกำลังดูและอ่าน และสัปดาห์ข้างหน้า — วาดจากแคช ไม่ใช้เครือข่ายของตัวเอง การตรวจเบื้องหลังสามารถแจ้งตอนใหม่ได้แม้ปิดแอปอยู่

การตรวจจับบน Android ใช้ Jellyfin: ชี้ Karasu ไปที่เซิร์ฟเวอร์ของคุณ แล้วตอนที่เล่นอยู่ที่นั่นจะนับถอยหลังสู่การอัปเดต แม้ปิดหน้าจอ หากคุณอนุญาตให้บริการติดตามทำงาน

เมื่อติดตั้งจาก F-Droid Karasu รับการอัปเดตจาก F-Droid ส่วน APK จากรุ่นที่เผยแพร่บน GitHub จะดึงเองและเปิดตัวติดตั้งของระบบ Karasu คุยกับ AniList กับเซิร์ฟเวอร์ Jellyfin ที่คุณตั้งไว้ กับ GitHub สัปดาห์ละครั้งเพื่อรับข้อมูลจากชุมชนว่าตอนต่อข้ามซีซันอย่างไร และเมื่อคุณเปิดโปรไฟล์ ก็คุยกับโฮสต์ของรูปภาพในประวัติของโปรไฟล์นั้น ผ่านการดึงแบบจำกัดของตัวเอง Karasu ไม่มีเซิร์ฟเวอร์ของตัวเองและไม่มีการวิเคราะห์การใช้งาน
